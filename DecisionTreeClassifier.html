Antes de seguir con el paso 4 debemos pasar por esta explicación conceptual

    
Entendiendo la Programación Orientada a Objetos en Machine Learning sobre la clase DecisionTreeClassifier, sus métodos y parámetros.


    

      


from sklearn.tree import DecisionTreeClassifier

# DecisionTreeClassifier es la CLASE (la plantilla).
# 'modelo' es un OBJETO / INSTANCIA creada a partir de esa clase.

modelo = DecisionTreeClassifier(
    criterion="entropy",  # Criterio para realizar las divisiones
    random_state=0        # Semilla aleatoria para resultados reproducibles
)

# Métodos principales del objeto:
# modelo.fit(X, y)   -> Entrena el árbol usando X e y
# modelo.predict(X) -> Realiza predicciones (ŷ) para datos X
# modelo.score(X, y) -> Evalúa el modelo (devuelve accuracy)

      

      

        

          
DecisionTreeClassifier

          
          

            
Parámetros Principales

            
🔹 criterion: Criterio para realizar las divisiones (ej: "entropy").

            
🔹 random_state: Semilla aleatoria que permite obtener siempre el mismo resultado (ej: 0).

          


          

            
Métodos Principales

            
🌱 .fit(X, y): Entrena el árbol de decisión usando los atributos X y la respuesta real y.

            
🔍 .predict(X): Realiza predicciones (ŷ) para nuevos datos X.

            
🎯 .score(X, y): Evalúa el modelo. Devuelve la precisión (accuracy).

          

        


        

          
📌 Conceptos Clave de Programación

          
    
            
  • ¿Qué es una Clase? Es el plano, plantilla o molde (DecisionTreeClassifier). Define la estructura y el comportamiento del modelo.
    • 
            
  • ¿Qué es un Objeto / Instancia? Es el elemento concreto creado a partir del molde (la variable modelo). Posee espacio en memoria y puede llamar a los métodos como .fit() o .predict().
    •

PASO 7: ¿Cómo usar mi modelo con datos de entrada de texto?

    
Proceso completo para tomar datos ingresados en texto plano por un usuario, codificarlos y predecir con el modelo entrenado.


    

      


# ==========================================================
# ¿CÓMO USAR MI MODELO PARA PREDECIR NUEVAS ENTRADAS?
# ==========================================================

# 1. Simulación de campos de texto ingresados por el usuario
entrada_humedad = "Baja"
entrada_temperatura = "Alta"
entrada_clima = "Soleado"

# 2. Crear un DataFrame con el nuevo dato de texto
nuevo_dato = pd.DataFrame([{
    "Humedad_suelo": entrada_humedad,
    "Temperatura": entrada_temperatura,
    "Clima": entrada_clima
}])

# 3. Codificar exactamente con las mismas columnas que se usó en X
nuevo_dato_codificado = pd.get_dummies(nuevo_dato)

# Reindexar para asegurar que tenga TODAS las columnas de X (rellenando con False)
nuevo_dato_listo = nuevo_dato_codificado.reindex(columns=X.columns, fill_value=False)

# 4. Realizar la predicción con el objeto modelo ya entrenado
prediccion_nueva = modelo.predict(nuevo_dato_listo)

print("Resultado de la predicción para el nuevo caso:", prediccion_nueva[0])

      

      

        
Flujo de Predicción en Vivo

        

          
          
          
          
          
          
          
          
        

        

          Predicción (ŷ) generada por modelo.predict():
          
"Sí" (Se debe regar)

        

        

          Fundamentos: El modelo no entiende la palabra "Baja" directamente. Primero convierte la entrada de texto al formato de columnas numéricas que aprendió durante modelo.fit() y luego emite la respuesta.
