PASO 1: Las Entradas (x)

Representación numérica de las características de la planta para alimentar la red neuronal.

# Entrada codificada numéricamente para la red
# Humedad del suelo (x1): 0.20 (Baja / Seco)
# Temperatura (x2): 0.80 (Alta / Calor)
# Condición Climática (x3): 1.00 (Soleado)

import numpy as np

x1 = 0.20  # Humedad
x2 = 0.80  # Temperatura
x3 = 1.00  # Clima Soleado

X = np.array([x1, x2, x3])
print("Vector de Entrada X:", X)

Variables de Entrada

💧 x₁ (Humedad): 0.20 (Suelo seco)
🌡️ x₂ (Temperatura): 0.80 (Día caluroso)
☀️ x₃ (Clima): 1.00 (Soleado)
Fundamentos: Las redes neuronales requieren trabajar obligatoriamente con valores escalados en rangos numéricos continuos (habitualmente entre 0 y 1).

PASO 2: Los Pesos (w) y el Sesgo (b)

Parámetros iniciales que la red irá ajustando para aprender la importancia relativa de cada variable.

# Inicialización aleatoria/pequeña de Pesos y Sesgo
# w1: Peso para Humedad
# w2: Peso para Temperatura
# w3: Peso para Clima
# b : Sesgo (bias)

w1 = 0.10
w2 = -0.20
w3 = 0.05
b  = 0.10

W = np.array([w1, w2, w3])
print("Pesos iniciales W:", W)
print("Sesgo inicial b:", b)

Configuración Inicial de Parámetros

⚖️ Peso w₁: 0.10

⚖️ Peso w₂: -0.20

⚖️ Peso w₃: 0.05

🎯 Sesgo b: 0.10

Fundamentos: Al inicio del entrenamiento, la red no conoce las respuestas correctas. Por eso se le asignan pesos aleatorios o pequeños y el algoritmo los ajustará progresivamente.

PASO 3: La Suma Ponderada (z)

Multiplicación escalar de cada entrada por su peso respectivo más el sesgo.

# Cálculo de la Suma Ponderada z
# z = (x1 * w1) + (x2 * w2) + (x3 * w3) + b

z = np.dot(X, W) + b

print("Paso a paso:")
print("x1*w1 =", x1 * w1)  # 0.20 * 0.10 = 0.02
print("x2*w2 =", x2 * w2)  # 0.80 * -0.20 = -0.16
print("x3*w3 =", x3 * w3)  # 1.00 * 0.05 = 0.05
print("Sesgo b =", b)        # 0.10
print("Resultado z =", z)    # 0.01

Combinación Lineal Integrada

z = (0.20 · 0.10) + (0.80 · -0.20) + (1.00 · 0.05) + 0.10
z = 0.01
Fundamentos: El sesgo ($b$) permite trasladar la curva de activación horizontalmente para dar mayor flexibilidad a la neurona para adaptarse a los datos.

PASO 4: La Función de Activación (Sigmoide)

Mapea el valor continuo z a un rango de probabilidad entre 0.0 y 1.0 agregando no-linealidad.

# Función de Activación Sigmoide
def sigmoide(z):
    return 1 / (1 + np.exp(-z))

# Aplicar la activación al resultado z
a = sigmoide(z)

print("Valor z de entrada:", z)
print("Activación a (predicción):", a)

Transformación Sigmoidal

a = 1 / (1 + e⁻ᶻ)
a = 0.5025
Fundamentos: Sin las funciones de activación no lineales, las redes neuronales multicapa se comportarían simplemente como un modelo de regresión lineal ordinario.

PASO 5: Propagación Hacia Adelante (Forward Propagation)

Flujo completo de procesamiento desde los atributos de entrada hasta generar la salida.

def forward_pass(X, W, b):
    # 1. Suma ponderada
    z = np.dot(X, W) + b
    # 2. Función de activación
    a = sigmoide(z)
    return z, a

z, prediccion = forward_pass(X, W, b)
print("Predicción Forward:", prediccion)

Esquema de Flujo Forward

[x₁, x₂, x₃] Entradas
⬇️ (Multiplicar por W y sumar b)
z = 0.01
⬇️ (Aplicar f(z) Sigmoide)
a = 0.5025 Salida

PASO 6: Obtener una Predicción

Evaluación del resultado emitido por la red frente al valor real esperado.

# Valor objetivo real (y): 1.0 (Regar = Sí)
y_real = 1.0

print("Respuesta Correcta Esperada (y):", y_real)
print("Probabilidad emitida por la Red (ŷ):", prediccion)

# Si la probabilidad es mayor o igual a 0.50 el modelo dictamina Regar
decisión = "Regar" if prediccion >= 0.5 else "No Regar"
print("Decisión de la red:", decisión)

Comparativa: Realidad vs. Modelo

✅ Objetivo Real (y): 1.0 (SÍ requiere riego)
⚠️ Predicción de la Red (ŷ): 0.5025 (Incertidumbre casi al 50%)
Fundamentos: Aunque la salida supera ligeramente el umbral de decisión (0.50), la probabilidad estimada (50.25%) está muy alejada de la certeza (100%).

PASO 7: Medir el Error (Loss Function)

Cuantificación matemática de qué tan lejos estuvo la estimación realizada.

# Cálculo del Error Cuadrático Medio (MSE para un solo ejemplo)
# L = 0.5 * (y_real - prediccion)^2

loss = 0.5 * (y_real - prediccion)**2

print("Diferencia (y - ŷ):", y_real - prediccion)
print("Pérdida calculada (Loss):", loss)

Magnitud del Error

Pérdida Actual (Loss):
L = 0.1238
Fundamentos: La función de pérdida nos otorga una métrica cuantitativa. El objetivo final de la etapa de entrenamiento es minimizar esta métrica hacia valores cercanos a cero.

PASO 8: Retropropagación (Backpropagation)

Cálculo de gradientes (derivadas) aplicando la regla de la cadena para distribuir la responsabilidad del error a cada parámetro.

# Derivada del error respecto a z (delta)
# dL/da = -(y - a)
# da/dz = a * (1 - a)
delta = (prediccion - y_real) * (prediccion * (1 - prediccion))

# Gradientes de los pesos y el sesgo
grad_w1 = delta * x1
grad_w2 = delta * x2
grad_w3 = delta * x3
grad_b  = delta

print("Gradiente W1:", grad_w1)
print("Gradiente W2:", grad_w2)
print("Gradiente W3:", grad_w3)
print("Gradiente Bias:", grad_b)

Vector de Gradientes Calculados

∇w₁: -0.0249

∇w₂: -0.0995

∇w₃: -0.1244

∇b : -0.1244

Fundamentos: El signo negativo del gradiente nos indica en qué dirección debemos desplazar cada parámetro para lograr disminuir la pérdida en la próxima iteración.

PASO 9: Actualizar Pesos (Descenso de Gradiente)

Modificación efectiva de los parámetros y verificación de la mejora en la predicción final.

# Tasa de Aprendizaje (Learning Rate)
learning_rate = 1.0

# Regla de actualización: W_nuevo = W_viejo - lr * gradiente
w1 = w1 - learning_rate * grad_w1
w2 = w2 - learning_rate * grad_w2
w3 = w3 - learning_rate * grad_w3
b  = b  - learning_rate * grad_b

W_actualizado = np.array([w1, w2, w3])

# Re-evaluar Forward pass con parámetros actualizados
_, nueva_prediccion = forward_pass(X, W_actualizado, b)

print("Predicción previa:", 0.5025)
print("Nueva predicción tras 1 iteración:", nueva_prediccion)

Evolución del Aprendizaje

Predicción Inicial: 0.5025 (50.25%)
Nueva Predicción (ŷ):
0.5841 (58.41%)
Fundamentos: Tras una sola iteración de actualización, la estimación mejoró del 50.25% al 58.41%, acercándose progresivamente hacia la certeza esperada del 100%.
